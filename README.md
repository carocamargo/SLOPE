# SLOPE interactive figures

Interactive Plotly figures of the TWL budget by tide gauge.

- `index.html` – landing page
- `budget-buildup/` – budget build-up by gauge
- `event-budget/` – per-event budget by gauge

Open `index.html` in a browser, or view the published site via GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root) at https://carocamargo.github.io/SLOPE/.
